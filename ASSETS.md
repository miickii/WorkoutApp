# Exercise illustrations

All 27 seeded exercises have local SVG movement/equipment illustrations. These original vector drawings reuse the RepTrack visual style and fitting existing RepTrack illustrations; no third-party photos or external image requests are used. Missing movements have dedicated drawings, including incline dumbbell (rather than barbell) press, standing shoulder press, both row variants, hip thrust versus floor bridge, Smith calf raise, and the floor core movements.

The supplied name “Rumænsk splitsquat” is preserved verbatim. Its illustration and equipment description assume a rear-foot-elevated split squat with dumbbells and a bench. Confirm this interpretation with the intended user.

Farmer walk is a timed carry: its seed targets are 20–40 seconds. Other exercises start with editable 3 × 8–12 targets, not a prescribed training plan. No previous performance or working weight is invented. Bodyweight movements start at zero added weight. All original Danish exercise names are preserved.

Figures are simplified movement identifiers rather than personalized technique instruction.
